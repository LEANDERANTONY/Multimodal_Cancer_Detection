# ADR-005 - Pre-Registered Deployment-ROI Experiment and Mitigation Panel
**Date:** 2026-10-05
**Status:** Accepted
**Author:** Leander Antony A

---

## Context

All models so far were trained and tested on crops cut from PANORAMA's provided pancreas masks, which do
not exist in clinical use. The field's standard deployment pipeline is two-stage (segment the pancreas,
crop, classify). Whether the segmentation stage costs detection performance, or re-introduces the scanner
confound, is unmeasured in the literature we reviewed. Separately, the mitigation panel (ADR-003) still
needs a concrete design and a fixed selection rule before any run, to avoid the DomainBed critique.

## Decision

The full design is fixed in `docs/deployment_and_mitigation_design.md` before running either experiment.
Its key commitments:

1. **Deployment-ROI:** TotalSegmentator (primary, off-the-shelf) and an out-of-fold nnU-Net pancreas
   segmenter (secondary) replace the provided masks; same builder and margins. Measure the crops first
   (IoU, centre offset, lesion containment, failure rate — per scanner), then detection and the confound
   tax, oracle vs predicted, paired. If there is a gap, fine-tune on crops perturbed with the *measured*
   segmenter error distribution and re-measure.
2. **Mitigation panel:** local 2.5D (pretrained 2D backbone on slice triplets, attention pooling with an
   auxiliary loss); arms tuned ERM, group-balanced sampling, DFR, GRL/DANN, MAE self-supervised
   pretraining; scanner = domain label; **one pre-registered selection rule** (mean validation AUROC
   across scanners, model soup), 3 seeds; same evaluation trio as ADR-004.
3. **Planted-shortcut control:** an artificial scanner-correlated marker validates that each method can
   remove a shortcut known to be present.
4. **Fusion rule:** synthetic samples may augment training only; every reported number is from real patients.
5. Practices are borrowed from studied Kaggle grandmasters (ren4yu, sersasj, samson8) and tagged in the
   design doc; a "didn't work" list is kept there.

## Consequences

**Positive:** the main novelty is pre-registered, so results (including null results) are credible; the
deployment experiment answers the clinical-validity question directly.

**Negative / risks:** TotalSegmentator inference on raw scans is local-only (the 182 GB raw set is never
uploaded), so it runs on the 8 GB GPU; the panel adds weeks of local compute.
